Healthcare Data Analysis and Insights

Project Overview
This project focuses on analyzing healthcare data to uncover insights into patient health profiles, medical histories, and healthcare costs using Microsoft Excel. The goal was to transform raw healthcare data into meaningful insights through data cleaning, data transformation, data analysis, and interactive dashboard development.

Tools and Skills
- Microsoft Excel: Data cleaning, transformation, analysis, and visualization
- Data Cleaning: Identified and handled missing values, including '?' entries, using appropriate replacement strategies.
- Data Transformation: Split customer names into meaningful fields, converted surgery counts into numerical values, and standardized inconsistent data.
- Data Preparation: Created calculated columns for BMI-based Weight Status, HbA1C-based Diabetes Status, Date of Birth, and Age.
- Data Integration: Combined Medical Examinations, Hospitalization Details, and Customer Names tables using Customer ID and VLOOKUP.
- Data Analysis: Used PivotTables to explore health indicators, medical histories, and healthcare charges.
- Data Visualization: Created pie/donut charts, bar/column charts, and line/scatter plots to communicate key findings.
- Dashboard Development: Built an interactive Excel dashboard with slicers for Weight Status and Diabetes Status.

Key Analysis Areas
- Examined cancer history among smokers and non-smokers.
- Compared major surgeries and average HbA1C based on transplant history.
- Analyzed healthcare charges across weight and diabetes categories.
- Compared average healthcare charges across hospital tiers and states.
- Explored relationships between age, BMI, HbA1C, and healthcare charges.

Key Learnings
Through this project, I strengthened my practical Excel skills in data preparation, lookup functions, PivotTables, calculated fields, chart creation, and interactive dashboard design. I also learned the importance of data quality, consistent data formats, appropriate categorization, and selecting suitable visualizations to communicate insights effectively.

Project Outcome
Developed an integrated healthcare dataset and an interactive dashboard that consolidates key analyses into a single view, demonstrating how Excel can transform raw data into structured insights for healthcare reporting and decision support.
